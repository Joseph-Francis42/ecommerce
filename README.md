# APEX Athletics — Premium Sports eCommerce MVP

**APEX Athletics** is a high-fidelity, premium sports activewear and gear eCommerce MVP built using **React, TypeScript, Vite**, and styled entirely with **Vanilla CSS**. 

The app features a striking midnight-dark athletic aesthetic, responsive layouts, modular state management, custom micro-animations, and a complete checkout workflow.

---

## ⚡ Features

1. **Modern Landing Page**:
   - High-contrast Hero section with overlay visual elements, call-to-actions, and dynamic tags.
   - Core value-proposition cards with neon accents and hover effects.
   - Promo coupon showcases and category quick-link grids.
2. **Product Catalog & Filters**:
   - Interactive search bar with instant catalog filtering.
   - Quick category selectors (Apparel, Footwear, Gear, Tech).
   - Price sorting mechanisms (Low-to-High, High-to-Low, Top Rated, and Featured).
   - Detailed product modals highlighting sizing selectors, color selectors, tech specs, item quantity controls, and animations.
3. **Shopping Cart Drawer**:
   - Slide-out sidebar drawer overlaying content.
   - Quantity updates (+/-), removal buttons, and automated subtotal counts.
   - **Discount Coupons**: Type **`APEX20`** to apply a working 20% discount on cart items.
4. **Checkout Wizard & Receipts**:
   - Multi-step form tracking Shipping information, Payment information, and final Review.
   - Validation checks on fields, including card spacing formatting and expiration slashes.
   - Processing indicators (spinners) during deposit validation checks.
   - Order confirmation screens displaying unique Order IDs, itemized receipts, and estimated delivery dates.

## 🛠️ Technology Stack

- **Framework**: React 19 (TypeScript)
- **Bundler**: Vite
- **Styling**: Vanilla CSS (variables, grids, flexbox, glassmorphism, keyframes)
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18 or higher) and **npm** installed on your system.

### Installation

1. Clone or download the repository to your local workspace.
2. Open terminal in the directory and install all node dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the Vite local development server:
```bash
npm run dev
```
Once launched, click or visit the localhost URL provided (usually `http://localhost:5173`) in your browser to experience the MVP.

### Production Build

To compile TypeScript and compile the project into optimized, minified static files:
```bash
npm run build
```
The compiled files will be created in the `/dist` directory, ready for hosting.
